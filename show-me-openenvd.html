What this picture leaves out

The clock is illustrative. This scenario assumes an ordinary child obeys SIGTERM and a second child ignores it. Real exit timing varies. The grace slider maps to stop_grace_s (default: 5 s). Cleanup happens even after a successful parent exit, and before any retry. The supervisor sends SIGTERM, waits up to the grace period, and sends SIGKILL if the group remains.

A hostile descendant can create a new session and leave that group; the escape option demonstrates this limit. Complete containment, resource limits, and orphan reaping belong to the outer container/sandbox. A dead marker means no longer running in this model—not proof of complete descendant reaping.

02 / Three different boundaries

Who you are ≠
what you can reach.

A different user ID does not create a different network. Drag the task into a private network, then trace its route to the API and to a file.

A different UID does not stop a connection. This control-API request is rejected because it has no valid bearer token.

Shared filesystem → permission check

Private file. Access denied.

The daemon owns this mode-0600 file. The task has a different UID and cannot read it.

Identity controls permissions. Networking controls reachability. The bearer token controls the daemon.

Why the token deserves special care

The token is an administrator credential: it grants arbitrary command execution, including deliberately running as the daemon user with auto_uid=False. There is no read-only observer token. Tasks get explicit environment variables plus a standard PATH; the daemon's environment, including its token, is not inherited automatically.

What must be true before a task can run?

Dedicated UID/GID allocation is on by default; private networking is optional and off by default. A private network requires a dedicated, nonzero identity and actual Linux namespace capabilities. This model automatically keeps identity separation on while private networking is selected. If required protection is unavailable, the real implementation refuses to execute the command; it does not quietly remove the protection.

The private network has its own loopback interface. The daemon's loopback address is not reachable from there. This is not filesystem isolation: world-readable files remain readable. The API exception is a minimal public /health route; this experiment models privileged control routes.

03 / Time is a safety mechanism

A crash should buy time,
not another crash.

A broken command can fail forever. The supervisor spaces out fresh attempts—and gives on_failure a finite retry budget. Stretch the first delay and watch the later waits grow.

Every command fails. Width = waiting time on a fixed 120-second scale. Command runtime and process-group cleanup time are omitted; each wait starts after cleanup.

A foundation, not the entire RFC.

Existing environments do not automatically enable this daemon. Separate agent, grader, observer, and orchestrator policies; reset integration; filesystem snapshots; and harness telemetry remain part of the broader draft RFC 009.

The event writer has the full admin credential. Its bounded, in-memory source can lose events, replay on writer restart, and reset sequence numbers on daemon restart. It is a best-effort process log—not an agent trajectory or durable audit trail.

Evidence, with its limits attached.

Earlier local verification recorded 1,650 passing repository tests. The focused openenvd suite passed 134 tests, with 10 platform-dependent skips on macOS. Ruff passed; two pre-existing import-order warnings remain elsewhere.
